6. Safe daily Git workflow
==========================

# Inspect current changes.
git status
git diff

# Stage all changed, deleted, and renamed files.
git add -A

# Or stage only a chosen file.
git add path/to/file.txt

# Review what will be committed.
git diff --cached

# Create a local commit.
git commit -m "Describe the changes"

# Download and integrate newer GitHub commits without rewriting history.
git pull --rebase origin main

# Push normally without force-overwriting GitHub.
git push origin main

After the upstream is configured, these shorter commands work:
git pull
git push


7. Safe handling of local deletions
===================================

If folders or files were deleted locally and those deletions should be sent to
GitHub, stage the deletions explicitly:

git status
git add -A
git commit -m "Remove obsolete files"
git pull --rebase origin main
git push origin main

A normal push refuses to overwrite newer remote commits. If GitHub changed after
the local commit, pull with rebase first and then push again.

Do not use these commands unless intentionally discarding or rewriting data:

# Discards local tracked changes and makes the branch match GitHub.
# git reset --hard origin/main

# Permanently removes untracked files and directories.
# git clean -fd

# Can overwrite remote history.
# git push --force


8. Pulling GitHub as the local copy
===================================

To intentionally make the local branch match GitHub exactly, first create a
backup branch, then reset:

git branch backup-before-github-reset
git fetch origin
git reset --hard origin/main

This discards local tracked changes not present on GitHub. Use it only when that
is the desired result.


9. Conflict recovery
====================

# See files involved in a conflict.
git status

# After resolving a file, stage it.
git add path/to/resolved-file.txt

# Continue a rebase.
git rebase --continue

# Cancel a rebase and return to the pre-rebase state.
git rebase --abort

# Merge unrelated initial histories only when that is genuinely required.
git pull --no-rebase origin main --allow-unrelated-histories

# After resolving a merge conflict:
git add -A
git commit
git push origin main
